# Text Difference Checker

A utility for comparing corresponding lines of text.

## Features

- Line comparison
- Difference highlighting
- Change summary

## How to Use

Enter original and modified text, then compare.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Compare two identical passages.
- [ ] Change one line and inspect the reported difference.
- [ ] Test added and removed lines.

### Test Notes

Record the observed result and any reproducible issue after running the tests.
